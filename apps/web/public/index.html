Character catalog · Enka static definitions

This imports static avatar definitions only. Names resolve from a separately reviewed localization snapshot where hashes match; unmatched names remain unresolved. This does not import or infer an account roster. The source is contacted only when you request a preview.

Offline Enka localization import

Stage Enka's store/gi/locs.json as storage/imports/enka/locs.json, then run npm run enka-l10n:preview. The preview reports recognized languages and changes; approval activates labels for matching text hashes without changing the original IDs.

Character-reference coverage · KeqingMains TCL

Import the KQM character-page index to track page coverage. These records show that a reference page exists; they do not provide verified playable-roster completeness or imply that a full build guide exists.

Offline page evidence

Stage a downloaded index at storage/imports/kqm-tcl/index.html and approved character pages as storage/imports/kqm-tcl/pages/<slug>.html. Run npm run kqm-index:preview, review and approve the index, then run npm run kqm-pages:preview. Extracted text and displayed table values stay experimental and cannot feed calculations.

Cross-source character reconciliation

Compare approved Genshin-DB, Enka, and KQM TCL records. Numeric IDs are stronger links; exact normalized English names are suggestions. Field disagreements remain visible. This report never merges records or treats a guide page as proof of playable status.

Reviewed canonical character projection
