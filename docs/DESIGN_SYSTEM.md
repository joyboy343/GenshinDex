# Design system

The intended direction is Ethereal Fantasy: midnight navy surfaces, restrained violet and celestial teal, muted gold and silver accents, an original starfield, layered translucent panels, and legible typography. Navigation is a top bar with expandable contextual menus. No generic dashboard theme or permanent primary sidebar. The dependency-free local screen now includes account setup, Knowledge Library search/review, and a source catalog; its reusable React/Vite design system remains pending package availability.
